# Example: pure Remotion

Three compositions in `src/`:

| Id | Shows | Render with |
| --- | --- | --- |
| `Shapes` | text and shapes, a sound track, length from input props | defaults |
| `WebFont` | a font file shipped in `public/fonts`, loaded before the first frame | defaults |
| `Cube` | a three.js scene (WebGL) | `--webgl --processes-per-instance=2` |

The sound (`public/tone.wav`) is generated by `npm run assets`: a steady tone with a beep at every second. The white
square in the corner flashes on the same frames. Together they make a bad join or lost sync easy to see and hear.

## Run it

```bash
npm install                       # or `npm run setup` in the repository root

npm run local                     # bundle + render Shapes on this machine           -> out/local.mp4
npm run local:chunked             # two local "instances", two processes each        -> out/local-chunked.mp4

npm run docker:build              # build the image (needs Docker)
npm run docker                    # two local containers                             -> out/docker.mp4

npm run deploy                    # bundle + wrangler deploy (needs Docker and `npx wrangler login`)
openssl rand -hex 24 | tee /dev/stderr | npx wrangler secret put RENDER_SECRET
export RENDER_SERVICE_URL=https://rrh-remotion-only.<your-subdomain>.workers.dev RENDER_SECRET=<value>
npm run cloud                     # two Cloudflare instances                         -> out/cloud.mp4
```

Other compositions and options:

```bash
CLI="node ../../packages/cloudflare-containers/bin/remotion-cloudflare.mjs"
$CLI render Shapes --props='{"title":"A minute","durationInSeconds":60}' --concurrency=4 --out=out/minute.mp4
$CLI render Cube --webgl --processes-per-instance=2 --out=out/cube.mp4
$CLI still WebFont --frame=100 --out=out/still.png
$CLI render Shapes --local --frames=0-89 --scale=0.5 --out=out/quick.mp4
```

Check a result: `node ../../packages/core/scripts/verify.mjs out/local.mp4 --frames 300 --joins 100,200 --tone`.

## Use your own project

Replace `src/` and `public/`. Keep `remotion` and all `@remotion/*` packages on one exact version in
`package.json`. Run `npm run local` before you deploy. Every change to the composition needs `npm run deploy` again:
the bundle lives in the image.

## Files

| File | Purpose |
| --- | --- |
| `Dockerfile` | the render image: Chrome's libraries, fonts, your dependencies, the bundle, the task server |
| `wrangler.jsonc` | the service: Worker, Durable Objects, container image, limits |
| `build/sites/site` | the bundle made by `npm run site` (not committed) |
